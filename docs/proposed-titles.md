# Варианты тем

- Методы компьютерного зрения для выявления видимых дефектов продукции по фотоматериалам обращений при приёмке.
- Разработка и исследование моделей компьютерного зрения для оценки видимого состояния продукции по фотоматериалам приёмки
- Исследование методов глубокого обучения для распознавания продукции и выявления видимых дефектов на фотографиях при приёмке товара
