# Варианты тем

- Разработка ителлектуальной системы для выявления порченых товаров по видимым дефектам продукции на основе фотоматериалов.
- Разработка и исследование моделей компьютерного зрения для оценки видимого состояния продукции по фотоматериалам приёмки
- Разработка и исследование моделей компьютерного зрения для оценки состояния и детекции дефектов продукции
**- Разработка системы для оценки состояния и обнаружения дефектов продукции с помощью моделей компьютерного зрения**
